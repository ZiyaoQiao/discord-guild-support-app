# 燕云十六声 Discord App Use Cases

这个 starter 先把支援、资料、组队和配装流程跑通。后续扩展时，优先做能降低管理成本、沉淀帮会知识、提升活动效率的功能。

## 优先功能

1. 引导式支援队列
   - 收集分类、紧急度、玩家、玩法、截图和期望结果。
   - 输出结构化摘要到管理组频道。
   - 后续可加状态、负责人、关闭原因和历史记录。

2. 配装诊所
   - 收集武器、心法、奇术、属性目标和当前痛点。
   - 按 PvE、PvP、探索、治疗、坦克等方向路由给导师。
   - 后续可加 OCR 截图识别，帮助成员少填表。

3. 组队与活动规划
   - 创建 LFG 帖子，按钮加入，记录报名人。
   - 生成活动草案，包含时间、频道、职责和复盘人。
   - 后续可加自动提醒和日历视图。

4. 新人引导
   - 提供规则、时区、玩法身份、自我介绍和首场活动清单。
   - 后续可加自动身份组分配。

5. 知识库搜索
   - 中文关键词搜索游民星空攻略和 GameKee 燕云十六声 Wiki，英文关键词搜索 Fandom Wiki。
   - 搜索官方新闻和帮会自建资料。
   - 后续可加向量检索或人工精选 FAQ。

6. 中英文沟通辅助
   - 频道内快速互译，默认私密返回，必要时公开发送。
   - 管理组把英文资料整理成中文公告草稿。
   - 国际成员提交支援请求时先做基础翻译。

7. 表情包搜索
   - 按“猫猫无语”“笑死”“加班”等描述返回几个候选图片。
   - 默认仅自己可见，确认适合频道后点按钮发送选中的一张。

8. 自动消息反应
   - 指定用户发消息时自动添加固定表情反应。
   - 适合标记会长、指挥、管理组或活动通知消息。

## 管理组功能

1. 纠纷报告处理
   - 私密收集消息链接、截图、时间线和期望处理结果。
   - 记录处理人和结论。

2. 招募流程
   - 收集申请者角色名、时区、玩法目标、推荐人。
   - 输出候选人摘要到管理频道。

3. 名册健康度
   - 成员自助维护定位、武器、门派、服务器、时区。
   - 后续可显示活动覆盖缺口。

4. 每周摘要
   - 汇总开放工单、近期活动、新配装、未处理招募和待办。

## 已有命令

- `/support`：支援请求。
- `/wwm-guide`：快捷指南。
- `/event-plan`：活动草案。
- `/news`：官方新闻。
- `/steam`：Steam 状态和成就。
- `/wiki`：中英文百科搜索。
- `/meme`：表情包候选搜索。
- `/translate`：中英文互译。
- `/profile`：成员档案。
- `/lfg`：组队。
- `/build`：配装库。
- `/resources`：安全集成边界。
- `/presence-info`：Presence 跟踪说明。
- `/use-cases`：功能想法。
- `/auto-reaction`：指挥编辑自动消息反应规则。
- Gateway 自动反应：配置后监听指定用户消息并自动添加表情。
